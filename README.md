# Repositório de Programação C++

Este repositório contém uma coleção de programas em C++ desenvolvidos para aprendizado e prática de programação. Os códigos abrangem desde conceitos básicos até problemas mais complexos envolvendo estruturas de controle, matemática e algoritmos.

## Como Compilar e Executar
Compilação Básica
```bash
g++ -o programa arquivo.cpp
./programa
```
Exemplo:
```bash
g++ -o soma Soma.cpp
./soma
```
Compilação com Otimizações
```bash
g++ -std=c++11 -O2 -o programa arquivo.cpp
```

## Pré-requisitos

    Compilador C++ (g++ recomendado)

    Sistema Linux/Windows/macOS

    Terminal/Prompt de comando

Ferramentas Recomendadas

    Editor de Código: VS Code, Code::Blocks, Dev-C++

    Compilador: g++ (GNU Compiler Collection)

    Sistema Operacional: Qualquer um com suporte a C++
